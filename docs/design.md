# NanoFlowVision 设计系统

界面的设计事实在 [redesign/](redesign/README.md) —— 诊断、UX、视觉、组件与实施
五份文档，加一份[打磨记录](redesign/06-polish.md)与 `mockup.html` 的可点击草稿。
它已经全部落地：

- **视觉**：中性无色（chrome 不上色），选中用反相强调，亮暗两房。
  代码里的事实是 `src/theme.zig` 的 `Colors` 与对比度测试；照片上的纱底用
  `scrim`（黑 62%）—— 压在白照片上白字也要过 4.5:1。
- **外壳**：导航栏（根行 + 树 + 设置，右缘可拖宽）、命令栏（面包屑 + 搜索 +
  筛选 + 排序 + 密度）、状态条（计数与重量、游标位置、排序状态、监视点、
  测量进度线）。
- **交互**：选择集合（单击 / 加选 / 连选 / 框选 / 全选）、键盘游标、
  批量评分与回收站（多张先确认）、kit 菜单与对话框、失败态与等待态可辨、
  操作的 toast 回声、空目录的出口、测量中的骨架墙、大图的顶部条（序号、星级、
  信息、关闭）+ 胶片条 + 卡片式信息块 + 适应 ⇄ 1:1。
- **键盘**：全图见 Ctrl+/（`src/i18n.zig` 的 `keys_map`，设置面板页脚同入口），或
  [redesign/02-ux.md](redesign/02-ux.md) §5；⌘F 聚焦搜索。
