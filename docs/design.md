# NanoFlowVision 设计系统

一个内容优先的图片浏览器：**照片本身就是界面**，chrome 退到近乎单色，
只留一个有身份的强调色——暗房灯的琥珀。本文档是界面唯一的视觉事实来源
（single source of truth）；代码里的事实是 `src/theme.zig`。

## 检索验证（ui-ux-pro-max，2026-10-24）

- **风格**：Minimalism & Swiss Style（干净、留白、高对比、功能优先、双主题）——与实现一致。
- **配色**：Museum/Gallery 谱系高度吻合——破坏色 `#DC2626` 完全一致，边框近同，
  "白卡片 + 近白背景 + 单色 chrome"的排布相同。
- **有意偏离**：数据集的中性色带蓝灰倾向（slate `#475569` 一族）——观片工具刻意用
  无色偏的 zinc 灰阶，避免环境色干扰对照片色彩的判断；琥珀强调色是身份选择，
  对比合规（深墨在琥珀上 ~5.4:1）。
- **不适用**：检索给出的滚动叙事版式与 Google Fonts 配对是网页场景误匹配；本应用是
  原生桌面工具，字体用系统默认。

## 设计原则

1. **照片说话，chrome 沉默。** 界面用近中性灰阶，彩色只来自照片和琥珀强调色。
2. **一深一浅，内容最深。** 亮色主题下画廊比面板暗半步（照片坐在纸上）；
   暗色主题下画廊是最深的一步（照片在暗房里发光）。这是 Lightroom 一脉的排布。
3. **对比是硬性的。** 正文文字在其所在的表面上 ≥ 4.5:1，两个主题都成立；
   强调色上用深墨而非白字（琥珀上白字只有 ~3:1，深墨 ~5.4:1 起）。
4. **照片可明可暗，文字自己负责自己。** 大图上的信息面板自带黑色 scrim
   （45%），面板文字用主题无关的白色系——不依赖主题令牌。
5. **4/8 的间距节奏。** 缩略图间隙 8，网格内边距 16，工具栏高 48，树行高 28。
6. **圆角分三档。** 缩略图/小元素 8，菜单/面板 10，弹窗 10。

## 组件规格

- **大图信息面板**：黑 45% scrim、圆角 10、内边距 12；相机行白色 semibold，
  参数行白 78%，快捷键提示白 55%；标签 chips 白 14% 底、白字、悬停 24%。
  颜色不随主题——照片底下它永远可读。
- **缩略图悬停**：1px `border` 发丝线 + 右上角 "⋯"（次级按钮）。
- **选中行**（目录树）：琥珀底 + 深墨字；悬停行：`surface_hover`。
- **空状态**：居中 muted 文案——空文件夹 "No pictures here"，
  搜索无果 `No matches for "…"`。
- **排序分段控件**：`track` 底、选中段 `surface` 底 + semibold + 微阴影。
