# NanoFlowVision 设计系统

界面的设计事实在 [redesign/](redesign/README.md) —— 诊断、UX、视觉、组件与实施
五份文档，加上 `mockup.html` 的可点击草稿。它已经全部落地：

- **视觉**：中性无色（chrome 不上色），选中用反相强调，亮暗两房。
  代码里的事实是 `src/theme.zig` 的 `Colors` 与对比度测试。
- **外壳**：导航栏（树 + 打开目录 + 设置）、命令栏（面包屑 + 搜索 + 筛选 +
  排序 + 密度）、状态条（计数与重量、监视点、测量进度线）。
- **交互**：选择集合（单击 / 加选 / 连选 / 框选 / 全选）、键盘游标、
  批量评分与回收站（多张先确认）、kit 菜单与对话框、失败态与等待态可辨、
  操作的 toast 回声、大图的顶部条 + 胶片条 + 可收起的信息块 + 适应 ⇄ 1:1。
- **键盘**：全图见 Ctrl+/（`src/i18n.zig` 的 `keys_map`），或
  [redesign/02-ux.md](redesign/02-ux.md) §5。
