# 06 · 历史：为什么重设计、怎么落地、后来打磨了什么

这一份留作记录；界面的**规格**在 [02](02-ux.md)、[03](03-visual.md)、[04](04-components.md)，
截图在 [shots/](shots/)，事实以代码与测试为准。

## 一、2026-10 重新设计的缘由

旧界面（暖炭/奶油 + 琥珀）能做「看」，做不了「挑」和「找」。诊断里最硬的几条：

- 窄窗口下面包屑会被搜索框挤成 0 宽；计数被固定宽度裁掉。
- 没有选择集合、网格没有键盘：想「用键盘挑 100 张」做不到。
- 排序是五段文字加一枚不知指向的小箭头；密度不可调；没有滚动位置。
- 操作没有回声（删除、粘贴、重命名都静默）；失败态和等待态长得一样。
- 三级文字在暗房里只有约 2.6:1；设置面板没有遮罩。
- 大图没有文件名、序号、邻近导航、胶片条。

设计目标因此定为：三秒定位、三种节奏（扫视/挑拣/细看）都有最短路径、
键盘全可达、每个 >200ms 的操作都有回声、画面顺序永不意外改变、颜色全部过对比度线。

## 三、2026-11 的打磨

**修掉的缺陷**

- 快照原来用 nanoui 的默认主题（蓝滑块、蓝按钮）；测试器现在接收应用主题。
- 照片纱底黑 45% 压白照片只有 3.5:1；新增 `scrim` 令牌（黑 62%），
  tile 名字条、星级/⋯ chip、大图顶条、胶片条、缩放 chip 统一使用，并纳入对比度测试。
- 大图信息块原来压住顶条；现在是不透明卡片，停在大图左下、胶片条上方。
- 大图 fit 区域现在扣掉顶条与胶片条，照片不再钻到条下面。
- 英文单数：「1 pictures」→「1 picture」。

**补上的规格**

- 导航栏：根文件夹自己是一行（空根不再是一列空白，单击即可回到起点）；
  右缘 4pt 拖宽 200–360，双击复位 240，松手写 config。
- 命令栏：`⌘F` 聚焦搜索、xmark 清空、四个图标钮都有 tooltip；
  排序键与方向常驻在状态条（`Name ↑`）。
- 状态条：键盘游标位置（`#7` / `第 7 张`）。
- 网格：空文件夹给「Open folder / Rescan + 格式提示」；测量中画骨架墙。
- 大图：顶条加 info / close 两枚 chip；星标用金色；胶片条按照片比例、
  当前项加环、其余压暗、悬停白边、放不下时整体等比缩小。
- 设置：页脚 `⌘/ Keys` 入口。
- 键盘一览：从一坨等宽文本改成两列表格——键在左（mono、右对齐），动作在右，按四组排；
  Windows/Linux 上 Backspace 记为 `Del`（mono 字体没有 ⌫）。
- 大图：房间固定为深色（`room`，亮房 `#111214`），照片始终在同一个中性深底上判断；
  等待/失败的文字改用 `room_muted`，不再借用主题的次要色。

**有意偏离旧规格**

| 旧规格 | 现在 | 理由 |
|---|---|---|
| 照片纱底黑 45–55% | `scrim` 黑 62% | 45% 压白照片 3.5:1，过不了规格自己的对比度线 |
| 大图信息块黑纱 | 不透明 `panel` 卡片 | 03 §7 已把它列为照片上的例外；白照片上黑纱不稳 |
| 大图顶条只有序号/文件名/星 | 再加 info 与 close | 鼠标可达性；04 §8 原本就列了这两个按钮 |

## 四、全屏看图（2026-11）

- `F11`、macOS 的 `⌃⌘F`、大图顶条的 expand chip；网格里进入会先打开游标那张。
- `Esc` 的层级加了全屏一层；退出全屏保留大图，关掉大图也退出全屏。
- 全屏 2.5s 无输入，顶条/胶片条/缩放 chip 收起、fit 扩到整屏；一动就回来（直接显隐，不淡入）。
- 窗口：进入前记住矩形、样式与最大化；设置只写进入前的窗口；启动不恢复全屏。
- 平台：Windows `WS_POPUP`（`src/win.zig`），macOS `toggleFullScreen:`，Linux 退化为最大化；
  全部经 `src/screen.zig`，测试走替身，绝不碰 HWND。
