# 06 · 打磨（2026-11）

重新把屏幕、代码与 01–05 的规格对了一遍，修的是**规格已经说清楚、实现却没做到**的地方，
以及本轮才浮出来的真缺陷。设计语言不变：中性两房、照片是唯一有颜色的东西、
状态用明度与形状说。

## 修掉的缺陷

**1. 快照画的不是应用的颜色。** `ui.Tester` 不传主题时用 nanoui 自己的调色板，
于是所有截图里的滑块、勾选框、主按钮、对话框都是系统蓝（`#0A84FF`），
和「chrome 不上色」直接冲突。现在 `tests.zig` 的 `initTester` 把
`theme.forDark(state.dark)` 递给测试器，快照与窗口看到的是同一份主题。

**2. 照片上的纱底在白照片上不够黑。** 原来各处的 `黑 45%` 压在纯白照片上，
白字只有约 **3.5:1**。新增 `theme.Colors.scrim`（黑 62%，两房同值），
tile 的名字条、星级 chip、⋯ chip、大图顶条、胶片条、缩放 chip 全部改用它；
`theme.zig` 的对比度测试把「白字压在白照片的纱底上」也纳进断言（≥4.5:1）。

**3. 大图信息块压着顶条。** 原来信息块在 `(24, 24)`，与大图顶条（高 44）重叠，
顶条上的序号与文件名被盖住。现在信息块是**不透明卡片**（`panel` 底 + 1px 描边 + 阴影），
停在大图左下、胶片条上方——照片上唯一允许的不透明物，正是规格 §7 的例外条款。

**4. 大图照片被顶条和胶片条切掉。** fit 的可用区域现在扣掉顶条（44+16）与胶片条（76+16），
照片不会再钻到条下面。

**5. 英文单数。** 「1 pictures」→「1 picture」。

## 补上的规格

**导航栏**

- **根文件夹自己是一行**（此前树只画子文件夹）：根没有子文件夹时，侧栏曾是一整列空白，
  也没有回到起点的入口。现在根行常驻、默认展开，`No subfolders here` 落在根行下面。
- **右缘 4pt 拖拽改宽**（200–360，双击复位 240，松手写进 config）；抓取偏移量避免
  「按下即跳」。

**命令栏**

- **`⌘F` 把光标放进搜索框**（此前 checklist 记为「依赖焦点 API」，实际 `c.focus` 够用）；
  搜索框有字时出现 **xmark**，一键还给用户整面墙。
- **四个图标钮都有 tooltip**（侧栏、星级筛选、排序、密度、更多）；排序的 tooltip 写
  当前键（如「Sort by · Name」）。
- **排序状态常驻可见**：状态条右侧写 `Name ↑` / `名称 ↓`，贯彻「顺序即信息」，
  不再需要打开菜单才知道按什么排。

**状态条**

- **键盘游标位置**：游标存在时显示 `#7` / `第 7 张`。

**网格**

- **空文件夹有出口**：`Open folder`（主按钮）与 `Rescan`，外加格式提示；
  空态不再只有一句话。
- **测量中画骨架墙**：按当前密度算出列数铺 `well` 方块，
  「正在测量」时页面是一面正在长出来的墙，而不是一张白纸。

**大图**

- **顶条右端两枚 chip**：`info.circle`（折叠/展开信息块）与 `xmark`（关闭），
  鼠标用户不必记 Esc；两者都带 tooltip。
- **星标用 `grade` 金**，与网格一致；空星是白 45%。
- **胶片条**：格子保持照片比例（高 48，宽按 aspect 钳在 44–96），当前项 2px 环、
  其余 0.72 不透明度、悬停 1px 白边；15 格放不下时整体等比缩小，绝不溢出窗口。
- **信息块**：卡片式、左下、可折叠；标签 chip 与键位提示改用主题色。

**设置面板**

- 页脚加 `⌘/ Keys` 入口（关闭面板并打开键盘一览），把「键盘全可达」补到设置里。

## 测试与快照

- 新增：搜索的 `⌘F` 与 xmark、状态条游标位置（中英）、空文件夹的出口、根行与拖宽/复位、
  大图 chrome 不压照片、胶片条格子在窗口内。
- `zig build test`：**94 个测试全绿**；`wc -l src/*.zig` 仍全部 ≤ 600。
- `docs/redesign/shots/` 全部重拍（现在用应用自己的主题）。

## 与旧规格的差异（有意为之）

| 旧规格 | 现在 | 理由 |
|---|---|---|
| 照片纱底「黑 45–55%」 | `scrim` 黑 62% | 45% 压白照片只有 3.5:1，规格自己的对比度条款优先 |
| 大图信息块黑纱底 | 不透明 `panel` 卡片 | 03 §7 已把信息块列为照片上的例外；白照片上黑纱不够稳 |
| 顶条只有序号/文件名/星 | 再加 info 与 close 两枚 chip | 鼠标可达性；04 §8 原本就列了这两个按钮 |
