# 03 · 视觉语言

## 0. 一句话

> 界面自己不着色。暗房是中性石墨，亮房是中性纸白；照片是唯一有颜色的东西；
> 状态用**明度与形状**表达：悬停是提亮，选中是反相环，游标是内描边。

与现行方案（`docs/design.md`：暖炭 + 琥珀）的关系：**全新定值，不继承任何 hex**。
不继承的理由：暖底会参与照片的色彩判断（肤色与白平衡看着偏暖），而琥珀这种饱和色
在照片上不可靠 —— 同一枚琥珀环压在油菜花和雪地上，可信度完全不同。

## 1. 色板

命名不用 `primary/secondary`，用**材料名**：`page`（底）、`panel`（面）、`rail`（导航）、
`tile`（图块位）、`well`（占位）、`ink/ink2/ink3`（文字三级）、`line/line2`（描边）、
`veil`（遮罩）、`grade`（星标金）、`danger`、`ok`。括号里是 `src/theme.zig` 的字段名。

## 2. 强调色策略（为什么 chrome 不上色）

三个状态通道，各自有独立的视觉手段，绝不用同一个手段表达两件事：

| 通道 | 手段 | 颜色 | 何时出现 |
|---|---|---|---|
| **悬停** | 4% 提亮 + 1px `line2` 描边 | 无彩 | 指针在图块/行/控件上 |
| **游标**（键盘） | 1px **内**描边，距边 0pt | `ink3` | 网格里有键盘焦点时，永远有一处 |
| **选中** | 2px **外**环 + 左上勾章 + 未选中压暗到 55% | `accent`（反相） | 选择集合非空时 |
| **危险** | 文字/按钮变 `danger` + `trash` 图标 | `danger` | 删除相关，仅此一处 |
| **内容标记** | ★ 星形（金色）+ 数字 | `grade` | 有评分时 |

反相强调的具体含义：暗房里「强调」= 更亮（白环、白底黑字按钮），亮房里 = 更暗
（墨环、墨底白字按钮）。同一个 token（`accent`）在两套主题里天然相反，
所以 `kit` 的 `primary` 按钮、滑块、进度条、勾选框都不用改语义，直接跟着走。

**禁止**：用 `accent` 的色相（本方案里它无色相）表示「新」「推荐」「活跃」；
那是把强调稀释成装饰。需要区分时用形状（环 / 勾 / 内描边）或文字。

## 3. 字体

沿用系统里已用的两个族：正文 `Geist`、数字 `JetBrains Mono`（未安装则回退系统字体，
`Theme.font` / `Theme.mono_font` 已经这么配）。CJK 走系统回退面。

| 角色 | 字号 | 字重 | mono | 用在哪 |
|---|---|---|---|---|
| 显示 | 17 | bold | — | 大图信息块的相机名 |
| 标题 | 15 | bold | — | 文件夹名（面包屑末段）、对话框标题 |
| 小标题 | 13 | semibold | — | 分组、图块文件名条 |
| 正文 | 13 | regular | — | 菜单项、按钮、标签、路径 |
| 次要 | 12 | regular | — | 计数、状态条、提示行 |
| 微 | 11 | regular / semibold | — | 分组标签、快捷键提示、角标 |
| 数字 | 11 / 12 / 13 | regular | ✔ | 计数、大小、序号、EXIF、百分比 |

规则：
- **数字一律 mono**（`ui.TextStyle.mono = true`），包括「3 / 12」「24.6 MB」「1/250 s」——
  等宽数字让跳动的计数不左右晃。
- 中文行高用 `leading = 1.2`；英文单行用默认 1.0。
- 长文件名**单行裁剪**（放在 `.clip()` 盒里），不做多行省略 —— 多行会让图块高度变化，
  破坏瀑布流的稳定。
- 全大写**不用**（中英混排里没有意义，且中文无大小写）；用字重而不是大小写做强调。
- 数字与单位之间一个空格（`24.6 MB`），中文与数字之间也留一个空格（`3 张图片`，
  `i18n.zig` 现有格式串已经是这个写法）。

## 4. 间距、尺寸、圆角

4pt 基数；下表是可用值，不出现表外数字。

| 令牌 | 值 | 用途 |
|---|---|---|
| `s1` | 2 | 斑马行内、图标与文字基线微调 |
| `s2` | 4 | 菜单项之间、chip 内边距 |
| `s3` | 6 | 图块间隙、命令栏内控件间距 |
| `s4` | 8 | 控件内边距、行内左右 |
| `s5` | 12 | 卡片内边距、面板内边距 |
| `s6` | 16 | 内容区边距、面板外边距 |
| `s7` | 24 | 大图信息块外边距、空态上下 |
| `s8` | 32 | 空态与窗口边缘的距离 |

| 结构 | 尺寸 |
|---|---|
| 导航栏 | 240（可 200–360），行高 30，缩进每层 +12，chevron 可点区 16×24 |
| 命令栏 | 高 44；按钮 28×28；搜索框 30 高、宽 180–240；chip 高 22 |
| 状态条 | 高 28；文字 12；进度线 2pt 高，横贯内容区顶边 |
| 内容区 | 边距 16，图块间隙 6 |
| 图块 | 圆角 4（照片本身），角标 chip 24×24 圆角 5，文件名条高 22 |
| 大图 | 顶部条 40，胶片条 76（缩略高 48，间隙 4），信息块内边距 10 圆角 6 |
| 浮层 | 菜单圆角 8，对话框圆角 12，toast 圆角 8，均带 1px `line` |

**密度三档**（目标行高，不是列数）：

| 档 | 目标行高 | 列宽 ≈ | 缩略图 | 适用 |
|---|---|---|---|---|
| 小 | 128 | 128 | 128（由 256 缩） | 一眼扫过上千张 |
| 中 | 256 | 256 | 256（`thumb_side` 现值） | 默认 |
| 大 | 512 | 512 | 512（需按档位请求） | 看构图、看脸 |

列数 = `clamp(round(可用宽 / (目标行高 + 6)), 1, 12)`，交给 `masonry.compute`。
三档的上限不是审美选择：缩略图缓存按尺寸分级会分裂（`thumbs.budget = 192 MB`），
五档会让缓存命中率掉得比手感涨得快。档位变化会重新解码可见区 —— 这是它该付的代价。

## 5. 层与影

| 层（`Style.layer`） | 内容 | 来源 |
|---|---|---|
| 0 | 页面、命令栏、状态条、图块 | 默认 |
| 5 | 大图（覆盖整个窗口） | 自定；必须低于 kit 的 10/11，否则确认框会被照片盖住 |
| 10 / 11 | 对话框底遮罩 / 对话框面板 | `kit.dialog.layer_backdrop` / `layer_panel` |
| 20 | 菜单、popover（排序/密度/筛选） | `kit.overlay.layer_popover` |
| 30 | tooltip | `kit.overlay.layer_tooltip` |
| 40 | toast | `kit.toast.layer_toast` |

投影只允许出现在「层」上：菜单 `shadowMd`、对话框 `shadowLg`、toast `shadowMd`。
**图块不投影**（一墙上百个投影会让画面发脏）；大图的照片框在亮房里用 `shadowMd`，
暗房里不用（黑影落在黑底上没有意义），改为 1px `line2` 描边。

## 6. 图标

颜色 `ink3`（次级）或 `ink`（主色）。

## 7. 照片怎么呈现

- **图块**：照片按原始宽高比填充（`ui.texture`，现状保留），圆角 4，
  底色 `tile`，照片到达前显示 `well` 骨架块（`kit.skeleton` 的呼吸节奏，但只画一次
  颜色不要每块都动画 —— 一墙同时呼吸会让整屏闪）。
- **不加工照片**：不加滤镜、不调色、不做「毛玻璃背景」（照片自己就是背景的替代品）。
- **角标永远在照片之上**：⋯ chip、勾章、星级都画在像素之后（现状的教训，
  见 `gallery.zig` 的注释：「像素会盖住先画的」）。
- **照片上的文字必须有纱底**：星级、文件名条、缩放 chip 一律带 `黑 45–55%` 的圆角纱底，
  只有纱底允许出现在照片上。唯一的例外是大图信息块：它可能压住照片任意部分，
  所以用不透明的 `panel` 卡片 + 1px 描边（见 `04-components.md` §8）。
- **大图**：照片原样居中，不圆角；亮房加 1px `line2` 边，暗房不加；`shadowMd` 只在亮房。
- **失败**：`well` 底 + `exclamationmark.triangle`（14）+ 「无法读取」（12, `ink2`），
  与「等待中」必须一眼可分（现状的失败与等待长得一样，是本次要修的第 13 条）。

## 8. 动效规格

时长以「不挡住手」为准；所有动画都通过 `ui.motion`（`present` / `number` / `keyframes` /
`spring`）或 `c.animate` 实现，不自造帧计数器。

| 事件 | 时长 / 缓动 | 说明 |
|---|---|---|
| 悬停提亮、描边 | 90ms tween | 指针来去都要快 |
| 按下 | 60ms | 只做 0.98 的 scale，不做位移 |
| 图块选中环 | 120ms tween | 环从 1px 到 2px，不做弹跳 |
| 单选变多选（压暗其他） | 140ms | 一次只播一次，不逐块 stagger |
| 菜单 / popover 出现 | `spring.snappy`（kit 默认） | 0.97 scale + 4pt 位移，与 kit 一致 |
| tooltip 出现 | 延迟 0.5s，淡入 120ms | 延迟与 `kit.tooltip` 默认一致 |
| 大图开关 | 200ms（进入：scale 0.98→1 + 淡入；退出：120ms 淡出） | 图片本体不缩放 |
| 大图浮层（顶条/胶片条） | 出现 140ms，隐藏 200ms（延迟 2.5s） | 指针不动才隐藏 |
| 胶片条当前项 | 120ms | 环 + 其他项 0.7 不透明度 |
| 骨架呼吸 | 1.6s 循环（`keyframes`） | 只在测量阶段；布局锁定后停止 |
| 布局锁定淡入 | 120ms | 整块一次，不逐块 |
| toast | 进入 200ms 上滑 6pt，退出 160ms | 自动消失 4s（危险 6s） |
| 滚动指示 | 滚动时出现，静止 1.2s 后淡出（200ms） | 不做回弹 |
| **网格滚动** | **不动画** | 滚动必须跟手 |
| **大图缩放/平移** | 保留现状（`c.animate`，速度 12） | 已按指针锚定，别改 |
| **测量完成后的重排** | **不动画**（先锁定再淡入） | 照片在眼皮底下移动是最坏的动效 |

**减少动效**开启时：删掉淡入、上滑、胶片条滑动、骨架呼吸与滚动指示淡出（改成直接出现），
保留选中环与悬停提亮的即时变化（它们传递状态，不是装饰）。

## 9. 反规则（做的时候别犯）

1. 不因窗口变窄而让任何文字被裁成「…」再消失 —— 宁可折叠成图标按钮（命令栏有断点规则）。
2. 不给照片加投影、倒影、光晕、渐变边。
3. 不用颜色单独表达状态（色盲与黑白截图是验收条件）。
4. 不使用图集外的图标名。
5. 不在照片上放常驻控件（例外只有两处：缩放 chip、大图信息块，都带纱底）。
6. 不动画滚动、不动画缩放、不动画重排。
7. 不引入第二套圆角体系：盒子只有 4 / 5 / 6 / 8 / 12 五档；
   进度条与滚动指示例外，用「宽度的一半」做胶囊（2 / 1.5），它们是细条不是盒子。
8. 不使用纯黑 `#000` 与纯白 `#fff` 作为界面底色（照片里的纯黑纯白需要背景比它更「软」，
   才能看出照片自己的极值）。
